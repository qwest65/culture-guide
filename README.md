# Культурный гид (CultureGuide)

Android-путеводитель по культурным объектам города с пешеходными маршрутами и режимом ведения по GPS.

Kotlin · Jetpack Compose · Yandex MapKit Full 4.45 · SQLite · minSdk 26 / targetSdk 35 · версия 0.8.0 (versionCode 9).

## Что умеет приложение

- **Нет пустых экранов.** При запуске загружается встроенный каталог, выбирается сохранённый (или первый) город и сразу открывается первый тематический маршрут: метки, пронумерованные остановки и пешеходная линия.
- **Пешеходный маршрут MapKit.** Каждый участок между остановками строится `PedestrianRouter`, длина берётся из `route.metadata.weight.walkingDistance.value` (метры); если вес пуст — сумма по секциям, в крайнем случае — длина геометрии.
- **Авто-перестроение.** Любое изменение списка остановок (выбор маршрута, добавление/удаление, перестановка) стирает старую линию, обнуляет расстояния и строит новую автоматически.
- **Режим ведения.** Приложение отслеживает геолокацию (GPS + сеть), показывает живое расстояние до текущей цели и весь оставшийся путь, рисует пунктирную пешеходную линию «от меня до цели» и само переключает цель, когда вы подходите к точке ближе чем на 45 м (срезанный путь к одной из следующих двух точек тоже засчитывается). Пройденные участки сереют, текущий выделен.
- **Поиск с автофокусом.** Поиск по названию, категории, адресу и описанию; выбор результата центрирует камеру и открывает карточку, «Показать на карте» вписывает все найденные объекты.
- **Карточка объекта.** Категория, адрес, расстояние от вас, развёрнутая историческая справка, маршруты, в которые входит объект, действия «Идти сюда», «В маршрут», «Показать на карте», «В Яндекс Картах», «Источник».
- **Адаптивная векторная иконка** (фон, передний план и monochrome-слой для тематических иконок Android 13+).

## Архитектура

```
app/src/main/java/ru/cultureguide/
├── CultureGuideApp.kt          ключ MapKit
├── MainActivity.kt             жизненный цикл, разрешения, MapKit, внешние ссылки
├── GuideController.kt          состояние и сценарии: город, маршрут, остановки, ведение, поиск
├── model/Models.kt             City, Place, RouteLine
├── data/CatalogDatabase.kt     SQLite + импорт assets/catalog.json (merge по полю revision)
├── location/LocationTracker.kt GPS + сетевой провайдер с выбором лучшего фикса
├── map/MapController.kt        слои карты: объекты, маршрут, подход к цели, пользователь; камера
├── map/WalkingRouteBuilder.kt  пешеходные участки PedestrianRouter, отмена устаревших запросов
├── navigation/Geo.kt           расстояния и форматирование
├── navigation/GuidanceEngine.kt  логика прибытия и переключения целей (без Android, покрыта тестами)
└── ui/                         Compose-экран и тема
```

Каждый тип объектов на карте живёт в своей `MapObjectCollection`, поэтому сброс маршрута — это `clear()` коллекции: полилинии гарантированно исчезают, метки не трогаются. Векторные иконки меток растеризуются вручную: `ImageProvider.fromResource` декодирует ресурсы через `BitmapFactory` и векторы не поддерживает.

## Данные

Каталог хранится в `app/src/main/assets/catalog.json` (формат `cultureguide`, версия 2). При изменении контента увеличьте `revision` — при следующем запуске приложение сольёт каталог с локальной базой: описания обновятся, новые объекты и маршруты добавятся.

## Сборка

```bash
gradle testDebugUnitTest assembleDebug
```

Ключ MapKit передаётся через переменную окружения `MAPKIT_API_KEY` или `local.properties` и не хранится в Git. В GitHub Actions нужен secret `MAPKIT_API_KEY`.

CI собирает APK на `main` и ветках `claude/**`; релиз `latest` публикуется только из `main`. Для идентификации сборки используйте `versionName`, `versionCode` и короткий SHA коммита в имени APK.
