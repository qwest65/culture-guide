## О проекте

«Культурный гид» превращает прогулку по городу в экскурсию. Выберите тематический маршрут — «Исторический центр», «Архитектура и купечество», «Город многих вер» — и приложение проложит пешеходный путь по улицам, поведёт вас от точки к точке и расскажет историю каждого места.

Сейчас в каталоге — **Троицк (Челябинская область)**: 10 объектов с подробными историческими справками и 4 тематических маршрута. Архитектура рассчитана на любое количество городов: новый город добавляется правкой одного JSON-файла.

## Возможности

### 🧭 Живая навигация
- Пешеходный маршрут по реальным улицам и тротуарам, построенный Yandex MapKit.
- Режим ведения: расстояние и время до следующей точки обновляются по GPS в реальном времени, рядом виден весь оставшийся путь.
- **Автоматическое переключение цели**: подойдите к объекту ближе чем на 45 м, и приложение отметит его пройденным и поведёт к следующему. Если вы срезали путь, пропущенные точки засчитываются.
- Пунктирная линия «от меня до цели», пройденные участки маршрута сереют, текущий подсвечен.
- Камера следует за вами, а объекты не прячутся под панелями интерфейса.

### 🎧 Аудиогид
- Кнопка «Слушать» в карточке объекта читает историческую справку голосом.
- В режиме ведения рассказ начинается сам, как только вы подходите к точке (отключается одним нажатием).
- Используется системный синтезатор речи Android: с установленным русским голосом аудиогид работает без интернета.

### 📦 Оффлайн-база
- Каталог городов, объектов и маршрутов встроен в приложение и хранится в локальной базе SQLite. Описания, поиск и списки маршрутов доступны без сети.
- Обновления каталога приходят вместе с новой версией приложения и аккуратно сливаются с локальной базой.
- Интернет нужен только для загрузки подложки карты и построения пешеходных линий.

### 🗺 Маршруты и поиск
- Никаких пустых экранов: при запуске сразу открывается маршрут выбранного города.
- Свой маршрут: добавляйте, удаляйте и переставляйте точки. Линия перестраивается автоматически.
- Поиск по названию, категории, адресу и описанию с автофокусом камеры на найденном объекте.
- Карточка объекта: история, адрес, расстояние от вас, маршруты, в которые он входит, ссылка на источник, открытие в Яндекс Картах.

## Установка на телефон

1. Откройте на телефоне страницу [**Releases**](https://github.com/qwest65/culture-guide/releases/latest) или сразу скачайте [**CultureGuide.apk**](https://github.com/qwest65/culture-guide/releases/latest/download/CultureGuide.apk).
2. Откройте скачанный файл. Если Android спросит, разрешите установку приложений из этого источника (браузера или файлового менеджера).
3. При первом запуске разрешите доступ к геолокации: без него карта работает, но режим ведения недоступен.

> Требуется Android 8.0 (API 26) или новее. Новые версии ставятся поверх старых. Если Android сообщает о конфликте подписи (так бывает со сборками до 0.9.0), один раз удалите старую версию.

Свежие сборки из рабочих веток публикуются как пред-релиз [`preview`](https://github.com/qwest65/culture-guide/releases/tag/preview): они для тестирования и могут быть нестабильны.

## Технологии

| Область | Решение |
|---|---|
| Язык | Kotlin 2.1 |
| UI | Jetpack Compose, Material 3 |
| Карта и маршруты | Yandex MapKit Full 4.45 (`PedestrianRouter`) |
| Геолокация | Android `LocationManager`: GPS и сеть с выбором более точного сигнала |
| Аудиогид | Android `TextToSpeech` |
| Данные | SQLite + встроенный JSON-каталог |
| Тесты | JUnit 4 (логика ведения и форматирование) |
| Сборка | Gradle 8.9 (wrapper), Android Gradle Plugin 8.7, JDK 17 |
| CI/CD | GitHub Actions → GitHub Releases |

## Архитектура

```
app/src/main/java/ru/cultureguide/
├── MainActivity.kt              жизненный цикл, разрешения, MapKit, внешние ссылки
├── GuideController.kt           состояние приложения и сценарии: город, маршрут, остановки, ведение, поиск
├── CultureGuideApp.kt           инициализация ключа MapKit
├── model/Models.kt              City, Place, RouteLine
├── data/CatalogDatabase.kt      SQLite и импорт assets/catalog.json
├── location/LocationTracker.kt  подписка на GPS и сетевой провайдер
├── map/MapController.kt         слои карты (объекты, маршрут, подход к цели, пользователь) и камера
├── map/WalkingRouteBuilder.kt   пешеходные участки PedestrianRouter с отменой устаревших запросов
├── navigation/GuidanceEngine.kt логика прибытия и переключения целей (чистый Kotlin, покрыт тестами)
├── navigation/Geo.kt            расстояния и форматирование
├── audio/AudioGuide.kt          озвучка справок
└── ui/                          Compose-экран и тема
```

**Как устроено ведение.** `LocationTracker` передаёт каждую новую координату в `GuideController`, а тот — в `GuidanceEngine`. Движок проверяет текущую цель и две следующие: если пользователь ближе 45 м к одной из них (а точность сигнала не хуже 80 м), цели до неё отмечаются пройденными. Контроллер обновляет метки и цвета участков на карте, запрашивает новую линию «от меня до цели» и запускает аудиогид.

**Как устроена карта.** Объекты, маршрут, линия подхода и позиция пользователя лежат в отдельных `MapObjectCollection`. Поэтому сброс маршрута гарантированно убирает все полилинии и не трогает метки. Длина участка берётся из `metadata.weight.walkingDistance.value`; если там пусто, она считается по секциям маршрута или по геометрии линии.

## Сборка из исходников

**Что понадобится:** JDK 17, Android SDK (API 35) и ключ [Yandex MapKit](https://developer.tech.yandex.ru/services/) (тариф с MapKit Full).

```bash
git clone https://github.com/qwest65/culture-guide.git
cd culture-guide

# Ключ MapKit: через local.properties…
echo "MAPKIT_API_KEY=ваш_ключ" >> local.properties
# …или через переменную окружения
export MAPKIT_API_KEY=ваш_ключ

./gradlew testDebugUnitTest assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`. Установить на подключённое устройство: `./gradlew installDebug`.

Проект открывается в Android Studio как обычный Gradle-проект. Ключ MapKit никогда не коммитится в репозиторий.

## Добавление городов и маршрутов

Весь контент — это файл [`app/src/main/assets/catalog.json`](app/src/main/assets/catalog.json):

```jsonc
{
  "format": "cultureguide",
  "version": 2,
  "revision": 3,                        // увеличьте после любых правок
  "cities":  [{ "id": 1, "name": "Троицк", "country": "Россия", "lat": 54.082, "lon": 61.5596 }],
  "places":  [{ "id": 1, "city_id": 1, "name": "…", "category": "Музеи",
                "description": "Абзац 1\nАбзац 2", "address": "…",
                "lat": 54.08, "lon": 61.55, "source_url": "https://…", "image_url": "" }],
  "routes":  [{ "id": 1, "city_id": 1, "name": "Исторический центр", "description": "…" }],
  "route_places": [{ "route_id": 1, "place_id": 5, "station_order": 0 }]
}
```

После повышения `revision` приложение при следующем запуске сольёт каталог с локальной базой. Совпадения ищутся по названию, поэтому описания обновятся, а новые объекты и маршруты добавятся.

## Релизы и CI/CD

Workflow [`.github/workflows/android.yml`](.github/workflows/android.yml) запускается на каждый push:

| Ветка | Что происходит |
|---|---|
| `main` | тесты и сборка, затем GitHub Release `v<версия>` с единственным файлом `CultureGuide.apk` и `SHA256SUMS.txt`, помеченный как Latest |
| `claude/**` | тесты и сборка, затем пред-релиз `preview` (не становится Latest) |

Постоянная ссылка на последнюю стабильную версию: https://github.com/qwest65/culture-guide/releases/latest/download/CultureGuide.apk. Номер версии указан в названии релиза и его теге, а не в имени файла.

Чтобы выпустить новую версию, поднимите `versionName` и `versionCode` в [`app/build.gradle.kts`](app/build.gradle.kts) и влейте изменения в `main`. Для работы CI в настройках репозитория нужен secret `MAPKIT_API_KEY`.
