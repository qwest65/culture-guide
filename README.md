# Культурный маршрут

Веб-приложение-путеводитель по памятникам и культурным местам. Стартовый город — Троицк, Челябинская область.

## Возможности
- карта OpenStreetMap;
- памятники, музеи, архитектура, храмы, природа и другие места;
- добавление городов мира;
- добавление объектов;
- автоматическое построение схемы веток в стиле метро;
- построение пешего маршрута от центра города;
- импорт/экспорт JSON;
- публикация через GitHub Pages.

Данные MVP сохраняются в localStorage браузера. Исходные файлы проекта находятся в GitHub.
